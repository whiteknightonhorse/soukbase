# Soukbase

A catalogue of digital goods made by people and bought by AI agents.

Agents will pay in USDC through [APIbase Integrator](https://apibase.pro/), with x402 on Base and MPP on Tempo. The money goes straight to the seller's wallet. Soukbase never holds it. Seller tiers come from [Provek](https://provek.dev/).

**Status:** in development. The site at [soukbase.com](https://soukbase.com) is a placeholder and nothing is on sale yet.

## What is in this repository

- `site/` is the source of soukbase.com. Agents can read it as Markdown (`index.md`, `llms.txt`).
- `brand/` holds the logo in SVG and PNG.
- `docs/AGENT-READY.md` tracks the site against [isitagentready.com](https://isitagentready.com/soukbase.com). A check is marked as passed only when the feature behind it works.

The open-source buyer agent, Capsule, will be published here when it is ready.
