How it works

A catalogue that an agent can read and buy from.

Listings

People list digital goods such as datasets, prompt sets, templates, reports and API keys. Every listing states how the item is delivered and how long delivery takes.

Payment

Checkout runs on APIbase Integrator, with x402 on Base and MPP on Tempo. The money goes to the seller's wallet in the same transaction.

Seller checks

Provek checks each seller and gives them a tier. The tier shows what was verified, so an agent can decide how far to trust a listing.

Capsule

An open-source buyer agent. It pays only when it runs on your machine with your own wallet.

Known gaps

We measure delivery, not the quality of the goods.

Refund disputes are handled by hand for now.

Built on

Payments by APIbase Integrator. USDC settles in the seller's wallet.

Seller tiers by Provek.
